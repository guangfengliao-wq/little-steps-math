# 小小数学家 · 数学花园

面向学前儿童的加减法学习应用。参考相邻「单词本」项目的学习、练习、错题复习和学习记录结构，使用 Vue 3、TypeScript、Vite 和 Capacitor，以 Android 平板为主，同时适配手机和网页。

## 第一版功能

- 5 以内、10 以内、20 以内三个阶段，可自由选择，不强制解锁。
- 看图学一学：调整两个数字和运算符，点击图标计数；加法展示两组数量，减法划掉拿走的物品。内置水果、动物、文具共 18 种图标，每题从全部物品中随机选择，无需手动切换；同题两组使用同一种图标，名称与量词同步更新。
- 动手练一练：每轮 10 题，可选加法、减法、混合；没有倒计时，不产生负数或超出阶段上限的答案。10 和 20 以内每轮都会包含超过上一阶段范围的题目。
- 新一轮包含 6 道普通计算和 4 道缺失数字填空；混合模式覆盖加法、减法的左数/右数留空。图示保持原题运算：求原数数全部、求拿走数数划掉部分、求加数数对应一组；读题和错题复习保留空格位置。已有练习继续原题型。
- 答错后提供实物图示，可继续尝试；按首次作答记录表现。
- 答题反馈参照单词本：答对绿色高亮、彩纸和上行和弦；答错红框抖动、哭脸和下行音效。重新输入可重试，答对效果播完后自动进入下一题，最后一题自动进入结果页；音效本地合成，系统减少动态效果时停用动画。
- 复习：保留答错题目，在之后的一轮首次答对时移除；复习可能涵盖多个阶段，每轮最多 10 题。
- 成长足迹：每完成一题收集一颗星，记录每轮题数与首次答对数；当前阶段的未结束练习可继续。切换阶段后，练习入口开始所选阶段的新一轮；开始前切回原阶段仍可续做。
- 家长设置：选择阶段与题型，仅影响新一轮练习。
- 切换学习阶段时，看图学习自动显示对应阶段的示例；仍可自行调整数字与运算符。
- 平板采用一屏布局，精简说明文字；错题每页 6 条、学习记录每页 3 条，通过按钮翻页。
- 题目朗读：使用设备的中文语音能力，无中文语音服务时显示提示，不保证离线朗读可用。

当前 20 以内阶段提供实物计数和练习，尚未单独实现凑十法、破十法的分步教学。

## 本地运行

使用 Node.js 22.6 或更高版本（测试使用 Node 内置 TypeScript 类型剥离）。

```sh
npm ci
npm run dev
```

默认地址：http://localhost:5174 。局域网设备可以使用开发服务输出的 Network 地址访问。开发服务不等于线上发布。

```sh
npm test
npm run build
npm run preview
```

测试覆盖三个阶段的全部出题组合、零、非负数、范围上限、单轮去重以及混合题型覆盖。

## Android

`android/` 已生成，应用标识为 `com.littlemath.garden`，与单词本独立安装。

```sh
npm run android:sync
npm run android:open
```

在 Android Studio 中等待 Gradle 同步后构建 APK，或在具备 Java 和 Android SDK 的环境运行：

```powershell
cd android
.\gradlew.bat assembleDebug
```

调试 APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。已验证网页构建、出题测试与 Capacitor 工程生成；浏览器检查覆盖 1280×800、1024×768、960×600、800×600、768×1024 的首页、学习、练习、结果、设置和列表分页，无视口溢出。尚未构建 APK、安装真机或验证 Android 语音。

## 数据与后续迭代

学习数据保存在本机 localStorage，无账号、服务器或跨设备同步。清除站点数据或卸载应用会丢失记录。浏览器和 APK 的记录彼此独立。

下一阶段可增加数的分合、凑十法/破十法动画、打包内置中文音频，以及 Android 真机验收与 APK 分享流程。

主要文件：`src/App.vue`（页面与学习状态）、`src/math.ts`（出题规则）、`src/style.css`（响应式样式）、`tests/math.test.mjs`（规则测试）。
